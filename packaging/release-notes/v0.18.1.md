Spotifast Free 0.18.1 brings in Spotifast 0.17.2, including Windows Soloist and playback fixes. Free playback still uses Spotify’s own web player on macOS and Linux. On Linux, it needs the separate Free helper for your architecture. Windows playback still requires Premium.

## New

- **Automatic updates.** Supported installs download signed Spotifast Free updates and install them on the next launch. You can turn this off in Settings → Updates. Package-managed installs show update instructions instead of replacing themselves.

## Fixed

- **Soloist starts on Windows again.** Spotifast falls back to the last working Soloist build if a newer one keeps crashing. Soloist also shuts down with the app, and its audio is less likely to break up on busy Linux systems.
- **Songs start where you picked them.** A song picked on your phone starts at the right track, playback can start again after shuffled autoplay (#1348), and the built-in Premium player no longer starts every song above a clicked queue row (#1317). Free playback still follows Spotify’s skip restrictions.
- **The full sign-in redirect address is visible again**, and transparent skin windows no longer have a rectangular shadow on Windows.
- **The release source archive uses the directory expected by the Fedora and Arch packaging recipes.**
